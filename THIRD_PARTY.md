# Third-party components

The source and example fixtures in this repository were written for this project.
No third-party source or media is vendored. Python's standard library is provided
by your Python installation under its own license. Runtime package dependencies:
none. Git, where required, is a separately installed program under its own license.

and their transitive dependencies. GitHub CI uses actions/checkout (MIT) and
actions/setup-python (MIT), pinned to upstream commit IDs. Their original
copyrights and licenses remain with their respective distributions.
