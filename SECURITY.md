# Security

Version 0.1.x is the currently maintained series. Please report sensitive
vulnerabilities through [GitHub private vulnerability reporting](https://github.com/KanadeK/git-portable-paths/security/advisories/new).
Do not include secrets or real user data in public issues. If private reporting
is unavailable, open an issue asking for a private channel without details.

This project performs no network requests and has no runtime package dependencies.
See the README for input trust boundaries, resource limits, and exclusions.
The host Python/SQLite/Git installations must be kept current by their operator.
